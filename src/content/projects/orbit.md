# Orbit Core Project

Orbit is a local-first, serverless project management system powered by markdown files on disk.

## Goals
- Dual interface for humans (Web UI) and AI agents (CLI / Filesystem)
- Wobbly sketch UI style based on `sketch_style.md`
- Fast drag-and-drop Kanban board
